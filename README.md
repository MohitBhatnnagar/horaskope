# Horaskope: AI Consumer Web Platform

Two-stage AI pipeline (draft model -> reviewer model -> human-review flag) behind a consumer horoscope app built on Lovable. About 11,000 readings served in beta. This repo shows the pipeline design with mock models; link the live Lovable project here.

**Inspired by:** Lovable, DeepSeek + Claude Sonnet two-stage pipeline (original implementation, no code copied).

## Run
```bash
python main.py
```
Pure Python 3.9+, no dependencies or API keys needed.

## Why this exists
Part of an AI-and-operations portfolio showing how AI workstreams can be designed, measured and governed.

## Live app
Built on Lovable (project: Cosmic Compass): https://horaskope.lovable.app
